## Key Features

* **Split-Screen Showcase Interface**: Auto-cycling carousel with campus landmarks soothing portal access.
* **Role-Based Access Control (RBAC)**: Students (Captcha), Faculty (2FA SMS), HOD (2FA SMS).
* **Two-Factor Authentication (2FA)**: Real-time automated STULP verification via Twilio Messaging API.
* **Role Dashboards**: Dedicated workspaces for Students, Faculty, and Department Heads.
